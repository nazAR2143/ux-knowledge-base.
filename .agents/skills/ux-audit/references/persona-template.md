# Persona Template

Use this template when creating a UX audit persona.

```
┌─────────────────────────────────────────────────────────────────┐
│  🧑‍💻  [FULL NAME]  —  "[Persona Nickname]"                     │
├─────────────────────────────────────────────────────────────────┤
│  Age: [age]             │  Location: [city, country]            │
│  Role: [job title]      │  Experience: [X years]                │
│  Company: [type/size]   │  Tech: [main tools/languages]         │
│  Primary Device: [device]                                       │
├─────────────────────────────────────────────────────────────────┤
│  MOTIVATION                                                     │
│  "[First-person quote about their goal]"                        │
├─────────────────────────────────────────────────────────────────┤
│  GOALS                  │  PAIN POINTS                          │
│  • [Goal 1]             │  • [Pain 1]                           │
│  • [Goal 2]             │  • [Pain 2]                           │
│  • [Goal 3]             │  • [Pain 3]                           │
│  • [Goal 4]             │  • [Pain 4]                           │
├─────────────────────────────────────────────────────────────────┤
│  TECHNICAL LEVEL: [████████░░] [label]                         │
│  UX EXPERIENCE:  [█████░░░░░] [label]                          │
│  MOBILE USAGE:   [████████░░] [label]                          │

```

## Bar Chart Key
- ██████████ Expert / Very Active
- ████████░░ Advanced / Active
- ██████░░░░ Intermediate / Moderate
- ████░░░░░░ Basic / Occasional
- ██░░░░░░░░ Beginner / Rare

## Persona Types for UX Knowledge Bases
- **Frontend Developer** — Code examples, accessibility, performance
- **UI/UX Designer** — Visual design, heuristics, research methods
- **Product Manager** — Checklists, metrics, business impact
- **QA Engineer** — Audit templates, testing methods, bug severity
- **Content Writer** — UX writing section, plain language, microcopy
